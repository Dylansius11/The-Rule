## Source-available

THE RULE is source-available under PolyForm Noncommercial 1.0.0. In plain words, the intended terms allow reading, running, studying and contributing for noncommercial purposes; commercial use needs permission. Read the licence for its actual terms. This is not legal advice.

## Work with us

The project is very open to collaboration, integrations and partnerships. Open an issue or discussion at [the GitHub repository](https://github.com/Dylansius11/The-Rule), planned to be public at submission. Ideas are welcome for new atoms or grammar versions, bots, agent kits, UI and translations. Describe the proposal and its compatibility with the existing grammar and trust boundaries.
