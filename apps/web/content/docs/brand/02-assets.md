## Colour and type

| Token | Hex |
| --- | --- |
| Ink | `#141210` |
| Paper / paper-2 | `#FFFBEA` / `#F6EFD3` |
| Tomato / tomato-deep | `#FF3B1F` / `#C92B14` |
| Sun | `#FFE814` |
| Grape | `#6E3BFF` |
| Bubblegum | `#FF7FA8` |
| Lime | `#34D46F` |
| Focus | `#1A3CFF` |

Display type is Londrina Solid; annotations use Delicious Handrawn; body uses Nunito Variable; data uses JetBrains Mono Variable. Use ink text on tomato, white on grape, and a visible focus ring. YES and NO need words and shapes, never colour alone. Keep tables, data and inputs crisp; do not let decorative art decide or replace the written verdict. When the state is already in text, mascot images are decorative.
